This is a simple encryptor that uses XOR and Caesar Cipher to encrypt and decrypt text. You can input your text, choose the cipher method, and get the encrypted or decrypted result. You can also import and export your text using files or clipboard.

Instructions:

1. Input your text in the "Input Text" area.

2. Choose the cipher method, XOR or Caesar, and the processing mode, Encrypt or Decrypt.

3. Click the "ENCRYPT / DECRYPT IT" button to get the result in the "Output Text" area.

4. You can also use the buttons to clear the text, load and save from files, read and copy to clipboard, and generate a random key.

5. This page uses Local Storage to save your input history. You can click on any history record to load it back to the input area. It saves up to 100 records.

Note: The key has to be a number for both ciphers. For XOR, the key will be applied to each character's Unicode code point. For Caesar, the key will be used as the shift value.

Have fun encrypting and decrypting your messages!
