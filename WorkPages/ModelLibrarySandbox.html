Model Library Sandbox

Reference APIs from Poly Haven!

About This Work

This project is built upon Unity Networking.

The aim is to experiment with importing 3D models at runtime—by linking to existing model libraries—in order to craft a unique experience for players.

Many thanks to Poly Haven for their selfless dedication and open API. Their high-quality models have undoubtedly raised the bar for open-source assets. If possible, please consider supporting them!
